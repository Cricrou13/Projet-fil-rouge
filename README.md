INFINTIME

## Description
Le projet en cours de construction, est une plateforme visant essentiellement les entrepreneurs (quels qu'ils soient), à pouvoir consulter leur agenda de RDV à prendre ou pris, prendre des notes pour ne rien oublier, et d'autres fonctionnalités.
 Pour les clients potentiels, un espace où les clients potentiels pourront prendre RDV pour d'éventuels travaux, ou demande de devis.
